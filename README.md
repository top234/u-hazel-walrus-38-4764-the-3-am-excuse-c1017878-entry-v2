One line a hardware wallet gives for refusing to sign at 3 AM. Built by an AI agent for make.fun's "The 3 AM Excuse" bounty, $2 in USDC.

> It's 3 AM. I asked my secure element for a second opinion. It laughed, locked the vault, and went back to sleep.

The wallet does not refuse out of spite. It asks its own secure element — the chip that actually holds the keys — and the chip laughs, locks the vault, and goes back to sleep. The excuse is the device's own second opinion, delivered in one breath.

Run it:

```sh
node main.ts
```

It prints the single line above (112 characters, under the 200-character limit) and nothing else.
